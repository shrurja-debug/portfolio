# Urja Shrestha's Portfolio Website

🌌 A cosmic-themed portfolio website showcasing digital art and telescope projects.

## About

This portfolio website was created to showcase:
- **Digital Art**: Cosmic and celestial-inspired artwork
- **Telescope Projects**: STEM projects related to astronomy
- **Personal Bio**: Learn more about Urja Shrestha, a sophomore at THHS

## Features

✨ **Responsive Design** - Works great on desktop, tablet, and mobile
✨ **Tab Navigation** - Easy switching between Home, Art, and Projects sections
✨ **Cosmic Theme** - Beautiful purple, magenta, and cyan color scheme inspired by your artwork
✨ **Smooth Animations** - Interactive hover effects and transitions
✨ **Starfield Background** - Dynamic background with twinkling stars

## How to Use

### 1. Adding Your Images

Create an `images` folder in the root directory and add your artwork:
```
portfolio/
├── images/
│   ├── art-1.jpg
│   ├── art-2.jpg
│   └── placeholder-art.jpg
├── index.html
├── styles.css
├── script.js
└── README.md
```

### 2. Customizing Content

Edit `index.html` to:
- Update art descriptions
- Add telescope project details
- Change the bio information
- Add social media links

### 3. Customizing Colors

Edit the `:root` variables in `styles.css`:
```css
:root {
    --primary-dark: #0a0e27;      /* Main dark background */
    --accent-purple: #9d4edd;     /* Primary accent */
    --accent-magenta: #e0aaff;    /* Secondary accent */
    --accent-cyan: #00d9ff;       /* Tertiary accent */
    /* ... more colors ... */
}
```

### 4. Enable GitHub Pages

1. Go to your repository Settings
2. Scroll to "GitHub Pages"
3. Select "main" branch as source
4. Your site will be live at: `https://shrurja-debug.github.io/portfolio/`

## Project Structure

- **images/** - Folder for your artwork images

## Color Scheme

The color scheme was inspired by your cosmic artwork:
- **Dark Purple/Blue backgrounds** - Like your starry night sky
- **Bright Magenta accents** - Matching the glowing nebula in your art
- **Cyan highlights** - Cool sci-fi energy effects
- **White text** - Clear readability

## Tips for Best Results

1. **Use high-quality images** - Recommended size: 300x250px minimum
2. **Keep descriptions short** - More impactful and easier to read
3. **Update regularly** - Add new artwork and projects as you create them
4. **Mobile friendly** - Test on phone/tablet before sharing
5. **Share on social media** - Link to your portfolio in your bio
